# Licenses and dependencies

All original SlopOS source code is released under the **0BSD** license
(see `LICENSE`). SlopOS does not incorporate or translate any GPL, LGPL,
AGPL, or other copyleft implementation code.

## Dependencies used at build/run time

| Component | License | Role |
|-----------|---------|------|
| GCC / binutils | GPLv3 (toolchain only) | Compiles the kernel and user programs; the generated binaries are SlopOS's own output, not GPL code. |
| GRUB 2 (grub-mkrescue) | GPLv3 | Bootloader that loads SlopOS via multiboot2; SlopOS is a separate program loaded by GRUB. |
| QEMU | GPLv2 | Virtual machine used to run/verify SlopOS. |
| xorriso / mtools | GPLv3 | ISO assembly tools. |

None of these are linked into the SlopOS kernel or user programs; they are
host tools used only to build and run the system.

## Bundled assets

* The 8x16 bitmap font (`src/font8x16.c`) is generated by
  `tools/genfont16.py`. The glyph shapes are original to SlopOS (0BSD).
  No third-party font data is copied.
* The ISR table (`src/isr_table.c`) is generated by `tools/genisr.py`
  (SlopOS, 0BSD).

## Originality

SlopOS is written from scratch for this project. It is not derived from Linux,
a Linux distribution, an emulator-hosted application, or a ported operating
system. It implements its own boot, memory management, interrupts, scheduler,
graphics, terminal, and ELF loader.
